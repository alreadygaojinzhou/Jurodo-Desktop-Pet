# 兽劳动全角色桌宠 · 使用说明

住在桌面上的《兽劳动》角色们，用 VPet 核心引擎驱动。当前有 17 个带立绘角色，
可以在右键菜单「选择角色」中随时切换。

## 启动

双击 `TojirouPet.exe`。第一次启动会在右下角生成缓存，需要几秒。

- 关闭窗口不会退出：右键菜单「躲到托盘」，双击托盘图标召回
- 退出：右键菜单「退出」或托盘右键「退出」
- 默认会在当前用户登录 Windows 后自动启动，可在右键菜单「开机自启动」中关闭

## 操作

| 操作 | 效果 |
|---|---|
| 左键点头部 | 摸头，好感 +1.2、心情 +2.5，会有台词 |
| 左键点身体 | 摸身体，好感 +0.5 |
| 按住拖动 | 移动几像素就会跟手拎起来，松手放下 |
| 右键 | 打开菜单：选择角色 / 投喂 / 聊天 / 换装 / 大小 / 退出等 |
| 长按（约 0.4 秒） | 也会打开菜单 |

右键菜单里的「互动规则」可以随时查看完整操作、投喂数值和状态变化说明。

## 角色切换

右键 →「选择角色」，选择文治、斗次郎、熊手、雪之丞、武智、狮子堂、穴守、
北之纹、笹吉、宇野、狸丸、母亲、鸢高、野兽人、基维、黑市商人或梶丸。

每个角色分别保存饱食、心情和好感。切换回来时会继续使用该角色之前的数值。
主人公没有独立立绘，因此只保留文字资料，不进入桌宠角色列表。

## 投喂

| 食物 | 效果 |
|---|---|
| 烤肉 | 饱食 +26、心情 +6、好感 +1.5 |
| 饭团 | 饱食 +14、心情 +3 |
| 递根烟 | 心情 +16、饱食 -2（他叼烟的表情会出来） |
| 啤酒 | 心情 +11、饱食 +8 |

数值会随时间下降：饱食约 14 小时见底，心情约 10 小时见底。掉太低他会变成丧/呆的表情，也会催饭。

## AI 对话

右键 →「和当前角色说话…」，或托盘右键「对话…」。回车发送。

接口配置在程序目录的 `config.json`：

```json
{
  "ApiBaseUrl": "https://api.deepseek.com/v1",
  "ApiKey": "sk-...",
  "Model": "deepseek-chat",
  "Temperature": 0.9
}
```

任何 OpenAI 兼容接口都能用（DeepSeek / Kimi / 通义 / 智谱 / OpenAI…）。换成别家只改这三行，重启程序生效。

角色人设从 `CharacterData/characters.json` 读取，包含性格、说话方式、雷点、
关系位置和原台词样本。AI 对话还会从 `CharacterData/story.jsonl` 检索相关剧情，
不会把整部剧本一次塞进上下文。

## 换装

右键「换装」会显示当前角色实际拥有的服装，外加盘腿坐姿。展示几秒后自动回到平常样子。

## 存档

状态存在 `%LOCALAPPDATA%\TojirouPet\state.json`，日志在同目录 `log.txt`。
删掉 state.json 就重新开始（好感清零）。

## 素材

立绘和角色资料来自游戏《兽劳动》(Jurodo)。多角色动画由
`tools/CharacterPackGenerator/` 从 `素材/角色/` 合成，输出到
`PetMod/characters/<角色>/`（VPet 动画包格式，500×500 画布、四状态表情映射）。

自己改图或更新人设后重新执行：

```powershell
dotnet run --project tools/CharacterPackGenerator/CharacterPackGenerator.csproj -c Release
dotnet build -c Release -p:Platform=x64
```

## 已知限制

- 窗口是 500×500 缩放后的完整方形，宠物两侧的透明区域仍会挡住点击（暂未做逐像素穿透）
- 目前只有静态帧 + 呼吸微动，没有真正的走路/工作动画
- 部分次要角色立绘较少，西装、浴衣、盘腿等菜单只会显示实际存在的动作
- 只做了主屏定位，多屏下会固定在主屏右下角
